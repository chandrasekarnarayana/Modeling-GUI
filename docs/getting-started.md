# Getting Started

## Install

```bash
pip install modeling-gui
# Optional AutoML extras
pip install "modeling-gui[automl]"
```

## Launch

```bash
run_modeling_gui
# or
python -m modeling_gui
```

## 60-second Quickstart

1. Click **Load Demo Dataset**.
2. Pick what you want to predict (target column).
3. Click **Smart Analyze**.
4. Read metrics and coach-bar hints; open **What I did** to see a transparent summary.
5. Save a project or export a report if you want to revisit later.
