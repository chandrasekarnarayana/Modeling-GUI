# Modeling-GUI

No-code ML & stats GUI for CSV data – from beginner to expert.

## Vision & Philosophy

Most data workers are not programmers. Modeling-GUI bridges the gap with a guided, one-button Smart Analyze experience (Basic mode) and full control for power users (Expert mode). Transparency, explainability, and reproducibility are built in.

## Highlights

- Smart Analyze with optional AutoML and leaderboard.
- Basic/Expert modes, domain presets, coach bar guidance.
- Regression/classification/clustering/forecasting models.
- Explainability (global/local, SHAP optional), partial dependence, scenario testing.
- Data quality checks, drift warnings, model cards, projects, reports, and bundles.
