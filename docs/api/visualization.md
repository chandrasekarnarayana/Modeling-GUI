# API: visualization

Plot helpers (matplotlib-based):

- `plot_data`, `plot_regression`
- `plot_confusion_matrix`, `plot_confusion_from_predictions`
- `plot_tree_diagram`
- `plot_curve_fit`
- `plot_residuals`
- `plot_feature_importance`
- `plot_forecast`

Functions generally accept numpy/pandas arrays and return Matplotlib figures (where applicable).
