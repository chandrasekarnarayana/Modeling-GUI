# Model Cards & Version History

This walkthrough shows how to view and export model cards and filter version history in Modeling-GUI.

## Steps

1) **Run a few models**
   - Use Smart Analyze or run models manually (e.g., OLS and Random Forest).
   - Each run adds an entry to run history; best models can be saved as model cards.

2) **Open Model cards tab**
   - See each saved card with name, problem type, created time, and metrics.
   - Select a card to activate it for predictions or exports.

3) **Export a model card**
   - Select a card → click **Export model card…**.
   - Choose Markdown or JSON; export includes metadata, metrics, data summary, and notes.

4) **Filter version history**
   - Use the problem-type dropdown (All/Regression/Classification/Forecasting).
   - Use the model filter (type part of a model name) to focus on specific runs.
   - The table updates to show matching runs.

5) **Reuse**
   - Activate a past model from the table or load a project to restore prior runs.
