# Scenario testing (what-if)

Goal: adjust key features and see how the prediction changes.

Steps:
1) Train a model (Smart Analyze or manual).  
2) Go to **Scenario testing** tab (Expert mode).  
3) Choose a base row index (defaults to 0).  
4) Pick a top feature and adjust the slider/value.  
5) Read the updated prediction and delta text; optionally click **Show partial dependence** for that feature.  

Why it’s useful:
- Helps non-technical users see which levers move the outcome.
- Great for “what if customer spends +$50?” or “what if temperature rises by 2°C?” quick checks.***
